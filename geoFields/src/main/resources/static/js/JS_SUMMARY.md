# JS Scripts Summary

Краткая шпаргалка по файлам в `geoFields/src/main/resources/static/js`.

## `script.js`

Главный фронтовый скрипт страницы с картой.

- Отвечает за загрузку полей организации и отображение их на карте `MapLibre`.
- Управляет боковой панелью пользователя и ссылками по ролям.
- Показывает popup по выбранному полю, историю посевов и блок пересечений.
- Загружает и переключает NDVI-слои для одного поля или для всех полей.

Ключевые функции:

- `apiPath(path)` - собирает URL с учетом локального `API_URL`.
- `loadSessionContext()` - загружает данные текущего пользователя и настраивает ссылки/CSRF logout.
- `loadFields()` - получает GeoJSON полей, создает source/layer и выставляет bounds.
- `setupLayerControls()` - вешает обработчики на переключатели подложки, полей и NDVI.
- `openFieldPopup(...)` - открывает popup по полю и кеширует его контекст.
- `setIntersectingFieldsOnMap(data)` - показывает на карте пересекающиеся поля отдельным source/layer.
- `updateNDVI()` - загружает NDVI для выбранного поля.
- `updateAllNDVI()` - загружает NDVI для всех загруженных полей.
- `loadIntersectingFields(fieldId)` - получает GeoJSON пересекающихся полей.
- `fieldPopupHtml(...)` - собирает HTML popup из summary, истории и блока пересечений.

Основные сценарии:

- клик по полю на карте;
- открытие истории поля в popup;
- загрузка пересечений;
- показ NDVI;
- переход на страницу агронома для редактирования истории.

## `agronomist.js`

Скрипт страницы агронома для работы с историей посевов и статусом поля.

- Загружает summary организации: поля, устаревшие поля, культуры, пользователя, CSRF.
- Показывает историю выбранного поля.
- Позволяет добавить, редактировать и удалить запись `field_crops`.
- Позволяет пометить поле устаревшим и восстановить его.

Ключевые функции:

- `mutatingHeaders()` - собирает заголовки для `POST/PUT/DELETE` с CSRF.
- `buildPayload()` - собирает тело запроса из формы истории.
- `loadSummary()` - загружает общую страницу и заполняет select-элементы.
- `loadHistory()` - запрашивает историю выбранного поля и перерисовывает таблицу.
- `enterEditMode(row)` - переносит выбранную запись истории в форму редактирования.
- `clearForm()` - сбрасывает форму в режим создания новой записи.
- `applyFieldIdFromQuery()` - автоматически выбирает поле из `?fieldId=...`.
- `fetchJsonWithOptionalMessage(...)` - helper для мутирующих запросов с разбором JSON-ответа.

Основные сценарии:

- выбор поля и просмотр истории;
- создание/редактирование/удаление записи истории;
- перевод поля в устаревшие;
- восстановление поля из списка устаревших.

## `org-admin.js`

Скрипт страницы администратора организации.

- Загружает список участников организации и их роли.
- Позволяет менять роль пользователя.
- Позволяет удалять пользователя.
- Показывает список активных полей и позволяет удалить поле целиком.

Ключевые функции:

- `postHeaders(csrfFromSummary)` - собирает CSRF-заголовки для JSON-запросов.
- `loadSummary()` - загружает summary по пользователям и перерисовывает таблицу.
- `apiJsonCall(method, path, body)` - общий helper для `POST/DELETE` с баннером и reload.
- `roleSelectHtml(...)` - строит `<select>` со списком ролей.
- `loadFields()` - получает список полей через agronomist API для блока удаления поля.
- `onSaveRole(ev)` - сохраняет новую роль пользователя.
- `onDelete(ev)` - удаляет пользователя.

Основные сценарии:

- просмотр пользователей организации;
- смена роли;
- удаление пользователя;
- удаление поля со связанными данными.

## `org-manager.js`

Скрипт страницы менеджера организации.

- Загружает ожидающие заявки на регистрацию.
- Позволяет принять или отклонить заявку.
- Работает с одноразовыми приглашениями в организацию.

Ключевые функции:

- `postHeaders(csrfFromSummary)` - собирает CSRF-заголовки для `POST`.
- `loadSummary()` - загружает summary, заявки и активные приглашения.
- `apiPost(path, body)` - универсальный `POST` helper с баннером и reload.
- `onPendingAction(ev)` - принимает или отклоняет заявку.
- `onRevoke(ev)` - отзывает приглашение.

Основные сценарии:

- обработка pending-заявок;
- создание новой invite-ссылки;
- отзыв существующего приглашения.

## `csrf.js`

Общий небольшой utility-файл для CSRF.

- Используется остальными страницами для чтения `XSRF-TOKEN` из cookie.
- Помогает собирать headers для запросов, которые меняют состояние.

Ключевые функции:

- `readXsrfToken()` - читает токен из cookie браузера.
- `csrfHeaders(extra)` - возвращает копию заголовков с добавленным `X-XSRF-TOKEN`, если токен найден.

## Коротко по связям

- `script.js` - карта, popup, NDVI, пересечения, пользовательская панель.
- `agronomist.js` - история посевов и статус поля.
- `org-admin.js` - пользователи, роли, удаление поля.
- `org-manager.js` - заявки и приглашения.
- `csrf.js` - общий CSRF helper для остальных страниц.
